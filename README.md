# PV String / MPPT Allocation (web app)

## Run on your own computer
    pip install -r requirements.txt
    streamlit run app.py
(opens in the browser at http://localhost:8501)

## Put it online for free (Streamlit Community Cloud)
1. Create a GitHub repository and upload these 4 files: app.py, pv_core.py, requirements.txt, README.md
2. Go to https://share.streamlit.io, sign in with GitHub, choose the repository, main file = app.py, Deploy.
3. Share the link. Every user gets their own session; nothing is stored.

Hugging Face Spaces (choose "Streamlit") works the same way.
